Academic & Reference Details

Original Research Paper & Project Documentation

Research Paper Reference:

Jiaxi Li, Guansong Pang, Ling Chen, Mohammad-Reza Namazi-Rad. "HRGCN: Heterogeneous Graph-level Anomaly Detection with Hierarchical Relation-augmented Graph Neural Networks." IEEE International Conference on Data Science and Advanced Analytics (DSAA 2023). DOI: 10.1109/DSAA60987.2023.10302626

Cloud Access Control Adaptation:

This project adapts the HRGCN hierarchical message passing layer and HetGDA self-supervised data augmentation specifically to Enterprise Cloud IAM Access Graphs (Users, Devices, Roles, and Resources) to identify zero-trust security anomalies without requiring labeled attack samples.

Project Submission Details:

  • Project: AI-Based Cloud Access Control using HRGCN
  • Framework: PyTorch, FastAPI, NetworkX, Vanilla Modern Web CSS/JS
  • Ablation Benchmarks: Full HRGCN vs HRGCN-SDR vs HRGCN-ER vs Vanilla HetGCN
